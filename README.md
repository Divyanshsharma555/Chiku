# Chiku ❤️

A premium romantic website made with only **HTML, CSS, and JavaScript** — no frameworks.

**Live repo:** [github.com/Divyanshsharma555/Chiku](https://github.com/Divyanshsharma555/Chiku)

---

## What’s inside

- Cinematic hero with floating hearts & glow
- Live together-counter (from Dec 2024)
- 5 flipping love cards with photos
- Masonry memories gallery + lightbox
- Personal love letter
- Reasons I smile timeline
- Floating music player (*I Thought I Saw Your Face Today*)
- Surprise confetti button

---

## Folder structure

```
├── index.html
├── style.css
├── script.js
├── images/
│   ├── card1.jpg … card5.jpg
│   └── memory1.jpg … memory12.jpg
└── music/
    └── perfect.mp3
```

---

## Run locally

Open `index.html` in your browser, or:

```bash
npx serve .
```

---

## Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import this GitHub repo
3. Framework Preset: **Other**
4. Click **Deploy**

---

## Customize

| What | Where |
|------|--------|
| Counter start date | `script.js` → `LOVE_START` |
| Photos | Replace files in `images/` |
| Song | Replace `music/perfect.mp3` |
| Letter text | `index.html` → Love Letter section |
